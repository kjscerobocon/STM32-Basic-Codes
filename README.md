# STM32 Basic Code Examples

A collection of beginner-friendly STM32 code examples for learning embedded programming. Each example focuses on a small task, such as blinking an LED, reading a push button, or sending data over UART.

## Getting Started

1. Choose an example from the repository.
2. Check which STM32 board or microcontroller the example targets.
3. Open the project in the development environment used for that example. If the folder contains only source files, use them in a project configured for your STM32 device.
4. Check the pin assignments and connect any required components.
5. Build and flash the firmware, then check the expected behavior on your board.

## Adding an Example

Put each new example in its own folder. Include a short note with the target board or microcontroller, the build tools used, any required wiring, and what you should see when the code runs.
